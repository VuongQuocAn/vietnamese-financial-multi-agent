## Design and Validation

1. Public LLMRequest/LLMResponse, Message, ModelIdentity; provider và model ID riêng,
   không đoán provider từ tên. Ordered text-only messages, correlation fields cố định.
2. OutputSpec text/json, SchemaReference opaque identity/version/dialect; không resolve
   refs. JSON syntax parser deterministic; schema validation chỉ lưu attestation có
   validator identity, không tự chạy validator hoặc claim provider enforce schema.
3. TextOutput/JSONOutput phân biệt bằng format; missing output khác text/json; trạng
   thái json_valid/invalid_json/unverified/schema_valid/schema_invalid riêng.
4. Usage counters nullable, source/status rõ; không suy total. Cost Decimal string,
   currency ba chữ ASCII hoa và provenance, unknown khác zero.
5. Strict types/extra forbid/finite numbers; missing/null/value giữ exclude_unset.
   Semantic consistency kiểm tra riêng trong model validators, không đánh giá tài chính.
6. Version llm_gateway_v1 bắt buộc; breaking field/type/status cần version mới và review;
   không silently accept future version/extras. Schema Draft 2020-12 mô tả cấu trúc,
   cross-field invariants do Python kiểm tra. Canonical JSON sorted keys/Unicode.
7. Error taxonomy tách rate_limit/quota, retryability metadata, origin; safe message
   cố định, provider code allowlist. Public parser lỗi chỉ code/path an toàn, không giữ
   input/raw exception/body. Text/schema identifiers là dữ liệu caller chịu trách nhiệm
   kiểm soát; serialization không phải DLP. Không có arbitrary metadata/provider kwargs.
